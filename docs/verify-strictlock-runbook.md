# 금고 모드(기간 약정 강력 잠금) — 실기기 검증 런북

기준일 D = 검증 시작일. 판정은 가능한 한 OSLog(`subsystem == "com.nagi.GoldTime"`)로 하고,
iOS 설정 동작(앱 삭제 금지·자동 날짜)은 육안으로 한다. 수집·조회 명령의 함정(sudo는 사용자
터미널, `/usr/bin/log` 절대경로, `--info --debug`)은 [working-rules](agent/working-rules.md)
"실기기 OSLog 수집" 참조.

## ⚠️ 검증 전 반드시 읽기

- **금고는 진짜로 못 푼다.** 검증용 약정은 반드시 **1일**로, 자주 안 쓰는 앱 그룹으로 건다.
  실수로 30일을 걸면 그 그룹은 한 달간 편집·삭제·연장이 전부 잠긴다(의도된 동작).
- **denyAppRemoval은 기기 전체다.** 약정이 활성인 동안 검증 기기에서 **모든 앱**을 지울 수
  없다. 검증 중 다른 앱을 지울 일이 없는 날에 진행한다.
- **실수 복구(비상구)**: 설정 → 스크린 타임 → GoldTime 권한 OFF → 전역 설정이 풀린다(Apple
  제약 — 기획상 수용된 유일한 탈출구). 재승인하면 약정이 그대로 복원되므로, 완전 초기화가
  필요하면 권한 OFF 상태에서 앱을 삭제한다.
- **금고가 켜진 기기에 금고 이전 빌드를 덮어씌우지 말 것.** 구버전은 `denyAppRemoval`을 끄는
  코드가 없어 기기 전체 앱 삭제 금지가 영구히 남는다(탈출구는 위 권한 OFF뿐). 롤백이 필요하면
  약정 만료를 기다리거나 권한 OFF 후 진행한다.
- 디버그 빌드(GTLog는 디버그 전용). 검증 중 앱 삭제·재설치 금지(판정 대상 바이너리 고정).

## 그룹 배치 설계 (세션 1에서 이대로 입력)

| 그룹 | 규칙 | 약정 | 검증 항목 |
|---|---|---|---|
| A `금고-만료` | 일일 한도 5분 | **1일** (D 저녁에 켬 → D+1 00:00 만료) | ①~⑥, ⑦ 자정 만료 |
| B `금고-진행` | 쿨다운(예산 5분/휴식 30분) | **3일** | ③ 쿨다운 휴식 차단, ⑧ 권한 철회/복원, 연장 |
| C `일반-대조` | 일일 한도 5분 | 없음 | 비금고 그룹의 연장·편집이 평소대로인지 대조 |

## 세션 1 — D일 저녁 (약 20분, 사람 개입)

1. **켜기 흐름** ①: 그룹 A 카드 → "금고 모드" 행 → 기간 1일 선택(미리보기 "오늘 23:59까지 잠겨요")
   → 고지 5행 확인(권한 철회 안내는 **없어야 정상** — 2026-07-13 제거)
   → "금고에 넣기" → 최종 확인 "네, 잠글게요".
   - 판정: 카드에 "금고 D-1" 배지 + 금고 행 부제가 만료일로 변경.
   - OSLog: `금고 전역 설정 적용 (denyAppRemoval·자동 날짜 강제)` (프로세스 GoldTime).
2. **전역 설정 실동작** ②:
   - 홈 화면에서 아무 앱 아이콘 꾹 → **"앱 제거" 항목이 없거나 비활성**.
   - 설정 → 일반 → 날짜와 시간 → **"자동으로 설정"이 켜진 채 회색(변경 불가)**.
3. **그룹 B에 3일 약정** 켜기(같은 흐름). 배지 "금고 D-3".
4. **편집·삭제 차단** ③: 그룹 A/B에서 —
   - 규칙 행 탭 → 편집기 대신 alert "금고 모드 잠금 중"(만료일 표기), 광고 게이트 미진입.
   - 항목(앱 선택) 영역 탭 → 같은 alert. / trash 아이콘 흐림·무반응.
   - 그룹 이름 인라인 수정은 **되는지**(허용 사양) 확인.
   - 대조: 그룹 C는 평소대로 편집기 진입·광고 게이트 동작.
5. **연장 차단** ④: 그룹 A 앱을 5분 써서 잠금 → Shield → "GoldTime 가기" → 잠금 선택지에서
   **1분/광고 버튼 없음 + 금고 안내 카드**(만료일), "그만 쓰기"만 동작. 그룹 C는 평소대로
   1분/광고 연장 가능(연장 후 재잠금 정상).
   - OSLog(이중 방어 확인은 선택): UI 차단이 정상이면 `연장 거부(금고 약정 중)` 로그는 안 뜬다.
6. **쿨다운 휴식 차단** ⑤: 그룹 B 앱을 예산(5분)만큼 써서 휴식 진입 → Shield → GoldTime 가기
   → 연장 버튼 없음(휴식도 못 풂 — 쿨다운 ADR의 의도된 예외).
7. **연장(기간 늘리기)** ⑥: 그룹 A 금고 행 → 시트에 남은 일수·시작/만료 표시, 프리셋 중
   1일은 비활성(만료가 늘지 않음), 3/7일·직접 입력만 활성 → **연장하지 말고 취소**(A는 내일 만료
   검증용). 그룹 B에서 7일로 실제 연장 → 배지 D-7, `strict_lock_commit` days=7.
8. **GA4**(선택): DebugView에서 `strict_lock_commit`(days=1,3,7) 확인.

## 자정 넘김 — D+1 (사람 개입 없음)

그룹 A의 1일 약정이 D+1 00:00에 만료된다. **앱을 열지 않은 채** 아침까지 둔다.

## 세션 2 — D+1 아침 (약 15분)

1. `sudo log collect --device --last 12h` 후 판정:
   - **자정 만료 해제** ⑦: `금고 전역 설정 해제` 로그. 프로세스가
     `DeviceActivityMonitorExtension`이면 extension 단독 해제(주 검증 목표), `GoldTime`이면
     메인 앱 BGTask가 먼저 지나간 정상 경합(1.2.0 ③과 동일 패턴 — 둘 다 통과).
   - 그룹 A 규칙(일일 한도) 자체는 평소대로 재무장됐는지(금고는 규칙 집행에 무영향).
2. 육안: 그룹 A 배지 사라짐·금고 행 "기간을 정해 강하게 잠가요" 복귀, 편집·연장 정상.
   앱 꾹 → **"앱 제거" 다시 가능해야 하나, 그룹 B(D-2)가 아직 활성이라 계속 막혀 있어야
   정상** — B가 활성인 동안 전역 설정 유지 확인이 곧 "약정 그룹 ≥1 ⇔ on" 판정.
3. **권한 철회 → 복원** ⑧ (그룹 B 활성 상태에서):
   - 설정 → 스크린 타임 → GoldTime 권한 OFF → Shield 사라짐 + 앱 제거 가능해짐(Apple 제약
     실측 — 기획상 수용).
   - GoldTime 열기 → 권한 복구 화면에 **금고 안내 1행**("약정이 그대로 이어져요") 표시,
     OSLog/GA4 `strict_revoke_detected` 1회.
   - 재승인 → 그룹 B 배지 D-N **그대로**(약정 복원), `금고 전역 설정 적용` 재로깅, 앱 제거
     다시 차단.
4. 그룹 B 정리: 검증 종료 후 B는 만료까지 두거나, 완전 정리가 필요하면 위 "실수 복구" 절차.

## 시뮬레이터 육안 항목 (실기기 불필요)

- [ ] 금고 시트: 기간 칩(1·3·7일 + 직접) 선택 → 만료 미리보기 갱신, **직접 칩 → 휠(1~30일)
      노출·칩 라벨이 고른 값으로 바뀜**, 고지 5행 아이콘·문구, 스크롤(.large),
      최종 확인 화면(자물쇠·accent 버튼·"다시 생각할래요"), 드래그 dismiss = 취소.
- [ ] 연장 시트: 남은 일수 헤더, 시작/만료 행, 만료 안 늘어나는 칩·휠 값 비활성(dim), 30일 약정
      상태에서 "이미 최대예요" + 버튼 비활성.
- [ ] 카드: 금고 배지 D-N 캡슐, 규칙 행·금고 행 자물쇠 아이콘, trash dim. 다크 모드·큰 글자.
- [ ] 차단 alert 문구(편집/삭제 각각 만료일 보간), en/ja 전환 표시(금고 모드/Vault Mode/金庫モード).
- [ ] LockOptions 금고 안내 카드 스타일(자물쇠 + accent 배경, "그만 쓰기" 유지).
- [ ] draft 그룹에는 금고 행이 없는지, 적용 직후 나타나는지.
