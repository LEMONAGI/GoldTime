# 연장 불가 모드(기간 강력 잠금) — 실기기 검증 런북

기준일 D = 검증 시작일. 판정은 가능한 한 OSLog(`subsystem == "com.nagi.GoldTime"`)로 하고,
iOS 설정 동작(앱 삭제 금지·자동 날짜)은 육안으로 한다. 수집·조회 명령의 함정(sudo는 사용자
터미널, `/usr/bin/log` 절대경로, `--info --debug`)은 [working-rules](agent/working-rules.md)
"실기기 OSLog 수집" 참조.

## ⚠️ 검증 전 반드시 읽기

- **연장 불가 모드는 진짜로 못 푼다.** 검증용 연장 불가 기간은 반드시 **1일**로, 자주 안 쓰는 앱 그룹으로 건다.
  실수로 30일을 걸면 그 그룹은 한 달간 편집·삭제·연장이 전부 잠긴다(의도된 동작).
- **denyAppRemoval은 기기 전체다.** 연장 불가 기간이 활성인 동안 검증 기기에서 **모든 앱**을 지울 수
  없다. 검증 중 다른 앱을 지울 일이 없는 날에 진행한다.
- **실수 복구(비상구)**: 설정 → 스크린 타임 → GoldTime 권한 OFF → 전역 설정이 풀린다(Apple
  제약 — 기획상 수용된 유일한 탈출구). 재승인하면 연장 불가 기간이 그대로 복원되므로, 완전 초기화가
  필요하면 권한 OFF 상태에서 앱을 삭제한다.
- **연장 불가 모드가 켜진 기기에 연장 불가 모드 이전 빌드를 덮어씌우지 말 것.** 구버전은 `denyAppRemoval`을 끄는
  코드가 없어 기기 전체 앱 삭제 금지가 영구히 남는다(탈출구는 위 권한 OFF뿐). 롤백이 필요하면
  연장 불가 기간 만료를 기다리거나 권한 OFF 후 진행한다.
- 디버그 빌드(GTLog는 디버그 전용). 검증 중 앱 삭제·재설치 금지(판정 대상 바이너리 고정).

## 그룹 배치 설계 (세션 1에서 이대로 입력)

| 그룹 | 규칙 | 연장 불가 기간 | 검증 항목 |
|---|---|---|---|
| A `연장 불가 모드-만료` | 일일 한도 5분 | **1일** (D 저녁에 켬 → D+1 00:00 만료) | ①~⑥, ⑦-a 자정 만료(그룹 단위) |
| B `연장 불가 모드-진행` | 쿨다운(예산 5분/휴식 30분) | **3일** | ③ 쿨다운 휴식 차단, ⑧ 권한 철회/복원, 연장, ⑦-b 전역 해제 |
| C `일반-대조` | 일일 한도 5분 | 없음 | 일반 그룹의 연장·편집이 평소대로인지 대조 |

> **⑦은 두 개로 쪼개야 한다(2026-07-27 실측으로 드러난 설계 착오).** 전역 설정은
> `hasActiveStrictLock` — 즉 **연장 불가 그룹이 0개가 될 때만** 해제된다. 그래서 A가 자정에
> 만료돼도 B가 살아 있으면 **`연장 불가 전역 설정 해제` 로그는 뜨지 않는 것이 정상**이다.
> A 만료로는 **⑦-a(그룹 단위 lazy 만료 + 전역 유지)** 까지만 검증되고, **⑦-b(전역 해제 로그)**
> 는 **마지막 그룹인 B가 만료되는 날 새벽**에만 자연 발생한다. 한 번의 자정으로 둘 다 보려면
> A·B를 **둘 다 1일**로 걸어야 하지만, 그러면 반대로 "다른 그룹이 활성인 동안 유지" 검증이
> 불가능하다. 연장 불가 기간은 **축소가 안 되므로**(강화만 가능) 중간에 앞당길 수도 없다 —
> 그룹 배치를 정할 때 이 트레이드오프를 먼저 선택할 것.

## 세션 1 — D일 저녁 (약 20분, 사람 개입)

   (구버전에서 구 토글을 Off로 두고 업데이트한 기기에서도 새 키 미설정=On이라 보여야 한다).

   다시 On이면 복귀한다.
   - 행 제목 옆 **ⓘ 버튼** 탭 → 2문단 팝오버(설정에서 옮겨 온 설명)가 뜨고, **시트가 열리지

     실기기 탭 정확도로 한 번 더 확인). 행의 나머지 영역 탭은 그대로 시트를 연다.
   - 홈 첫 진입 시 무료 베타 안내 alert이 **확인 버튼 하나**로 뜨는지("설정에서 확인" 버튼 제거).

   - 판정: 카드에 "연장 불가 D-1" 배지 + 연장 불가 행 부제가 만료일로 변경.
   - OSLog: `연장 불가 전역 설정 적용 (denyAppRemoval·자동 날짜 강제)` (프로세스 GoldTime).
2. **전역 설정 실동작** ②:
   - 홈 화면에서 아무 앱 아이콘 꾹 → **"앱 제거" 항목이 없거나 비활성**.
   - 설정 → 일반 → 날짜와 시간 → **"자동으로 설정"이 켜진 채 회색(변경 불가)**.
3. **그룹 B에 3일 연장 불가 기간** 켜기(같은 흐름). 배지 "연장 불가 D-3".
4. **편집·삭제 차단** ③: 그룹 A/B에서 —
   - 규칙 행 탭 → 편집기 대신 alert "연장 불가 기간이에요"(만료일 표기), 광고 게이트 미진입.
   - 항목(앱 선택) 영역 탭 → 같은 alert. / trash 아이콘 흐림·무반응.
   - 그룹 이름 인라인 수정은 **되는지**(허용 사양) 확인.
   - 대조: 그룹 C는 평소대로 편집기 진입·광고 게이트 동작.
5. **연장 차단** ④: 그룹 A 앱을 5분 써서 잠금 → Shield → "GoldTime 가기" → 잠금 선택지에서

## 자정 넘김 — D+1 (사람 개입 없음)

그룹 A의 1일 연장 불가 기간이 D+1 00:00에 만료된다. **앱을 열지 않은 채** 아침까지 둔다.

## 세션 2 — D+1 아침 (약 15분)

1. `sudo log collect --device --last 12h` 후 판정 (**⑦-a**):
   - 그룹 A 규칙(일일 한도) 자체는 평소대로 재무장됐는지(연장 불가 모드는 규칙 집행에 무영향).
   - **`연장 불가 전역 설정 해제` 로그는 이 시점에 없어야 정상**이다(B가 활성). 로그가 떴다면
     오히려 버그 — 연장 불가 그룹이 남아 있는데 기기 잠금이 풀렸다는 뜻이다.
2. 육안: 그룹 A 배지 사라짐·연장 불가 행 부제가 "잠기면 더 이상 연장할 수 없어요"로 복귀, 편집·연장 정상
   (= 만료가 lazy 판정으로 자연 복귀 — 별도 상태 전환 이벤트 없음).
   앱 꾹 → **"앱 제거"는 계속 막혀 있어야 정상** — 그룹 B가 아직 활성이기 때문이며, 이 "유지"
   확인이 곧 "연장 불가 그룹 ≥1 ⇔ 전역 설정 on" 판정이다.
3. **권한 철회 → 복원** ⑧ (그룹 B 활성 상태에서):
   - 설정 → 스크린 타임 → GoldTime 권한 OFF → Shield 사라짐 + 앱 제거 가능해짐(Apple 제약
     실측 — 기획상 수용).
   - GoldTime 열기 → 권한 복구 화면에 **연장 불가 모드 안내 1행**("연장 불가 기간이 진행 중이에요 — 권한을 다시 켜면 그대로 이어져요") 표시,
     `strict_lock_revoke_detected` 1회 — **OSLog에서 찾지 말 것**(2026-07-29 구 이벤트명
     `strict_revoke_detected` 실측): `AnalyticsRepositoryImpl`은
     GTLog를 전혀 호출하지 않아 분석 이벤트는 **Firebase 전용**이다. 확인은 GA4 DebugView이거나,
     이벤트 발생 다음 날 아침(D+1 08:25~09:00 export 도착 후) BigQuery 조회로 한다.
   - 재승인 → 그룹 B 배지 D-N **그대로**(연장 불가 기간 복원), `연장 불가 전역 설정 적용` 재로깅, 앱 제거
     다시 차단.
4. **기능 토글 끄기 방어**: 방어를 두지 않는다(2026-09-01 토글 재도입 시에도 미부활). 설정 토글은
   있지만 **끄기가 자유롭다** — 집행부가 게이트를 안 보므로 진행 중인 연장 불가 기간이 걸린 상태에서
   토글을 Off로 내려도 잠금은 유지·집행되고(`denyAppRemoval` 등) 잠긴 그룹의 행도 계속 보인다
   (`showsStrictRow`). 검증: 잠금 활성 그룹이 있을 때 설정 토글 Off → 잠긴 그룹 행·전역 설정이
   그대로인지, 잠기지 않은 그룹 행만 숨는지. 구독 페이월이 붙으면 **구독 만료 중 진행 중인 연장 불가
   기간**도 같은 계약(게이트 무관 유지)으로 커버된다.
5. **연장 차단** ④·**쿨다운 휴식 차단** ⑤을 세션 1에서 못 했다면 여기서 B로 수행한다 —
   B는 아직 활성이므로 언제든 가능하다(애플 TV 등 B의 앱을 예산만큼 사용 → Shield →
   GoldTime 가기 → 연장 버튼 없음 + 안내 카드).

## 세션 3 — B 만료 자정 직후 (약 5분, ⑦-b 전용)

마지막 연장 불가 그룹이 만료되는 자정에만 관측되는 항목이다. **앱을 열지 않은 채** 로그부터
수집한다(메인 앱을 먼저 열면 누가 해제했는지가 흐려진다).

**수집 타이밍이 판정 품질을 정한다 — `00:05~00:15`에 `--last 30m`이 최선이다.**
GTLog는 `Df`(Debug) 레벨이라 오래 보존되지 않는다: 2026-07-30 실측에서 오후 13:21에 수집하니
같은 시각 Apple 프레임워크 로그 75줄은 남았는데 GTLog는 2줄만 남아 `▶︎ intervalDidStart`까지
유실됐다(⑦-b 자체는 통과했지만 자정 재무장은 판정 불가로 남았다). **00:00 정각은 이르다** —
하트비트가 자정보다 수 분 늦게 발화한 실측(00:02:50)이 있다. 차선은 아침 일찍.

1. **전역 해제** ⑦-b: `연장 불가 전역 설정 해제 (denyAppRemoval·자동 날짜 강제)` 로그.
   프로세스가 `DeviceActivityMonitorExtension`이면 **extension 단독 해제(주 검증 목표)**,
   `GoldTime`이면 메인 앱 BGTask가 먼저 지나간 정상 경합(1.2.0 ③과 동일 패턴 — 둘 다 통과).
2. 육안: 앱 꾹 → **"앱 제거" 다시 가능**, 설정 → 날짜 및 시간 **수정 가능**으로 복귀.
3. **토글 끄기**: 활성 기간이 0개가 됐으므로 설정에서 "연장 불가 모드"가 **정상적으로 꺼지고**
   카드에서 연장 불가 행이 사라지는지.

편집/항목/삭제 차단 alert + **광고 다이얼로그 미노출**, 이름 수정만 허용, C 대조(광고 게이트
정상). ⑥의 "B를 7일로 연장"은 **실행하지 않았다**(A 만료 검증 보존 목적) — `days=7` 이벤트가
없는 것이 그 근거이고, 결과적으로 B가 3일 그대로 7/30에 만료돼 ⑦-b 관측일이 됐다.

### 세션 2 — 통과 (2026-07-29 아침)

⑦-a: A 만료 lazy 복귀(배지 사라짐·편집 가능) + **전역 설정 유지**(B 활성이라 해제 로그 없음이

**미판정 1건**: 자정 재무장(`자정 리셋 + 재무장 시작`)은 로그 유실로 판정 못 했다. 정황은

### 확정 피드백 — 소리를 뺐다 (2026-07-31)

"잠금 소리가 안 난다"로 시작해 **소리 자체를 포기**하는 것으로 끝났다. 기각 순서:
