## Review Notes (English — paste as-is)

```
GoldTime helps users limit their own screen time using Apple's Screen Time / Family Controls / ManagedSettings APIs. This version (1.3.0) adds a beta feature called "Locked-In Mode." Please read this before testing that feature.

WHAT LOCKED-IN MODE DOES
When the user activates Locked-In Mode on a group, GoldTime applies two device-level restrictions via ManagedSettings for the committed period:
  1. denyAppRemoval — blocks deleting apps. This is Apple's device-wide setting; GoldTime cannot scope it to only its own app.
  2. requireAutomaticDateAndTime — locks Date & Time to automatic, so the timer cannot be bypassed by changing the clock.
By design, the app intentionally has NO in-app "cancel/unlock" button during the committed period. The entire purpose of the feature is that the user cannot undo their own commitment on a weak impulse.

IT CANNOT BE TRIGGERED BY ACCIDENT
Activation is strictly opt-in and requires deliberate steps:
  (1) turn on the "Locked-In" option in Settings,
  (2) open a group that already has rules applied and choose a duration,
  (3) confirm through a two-step confirmation sheet.
The minimum duration is 1 day, and the mode releases automatically when the period expires.

HOW TO RELEASE IT IMMEDIATELY (IMPORTANT)
If you enable Locked-In Mode during review and need to remove the restrictions right away, revoke GoldTime's Screen Time permission:
  iOS Settings → Screen Time → (Apps With Screen Time Access) → GoldTime → turn off / remove access.
Revoking GoldTime's authorization also clears the global restrictions (denyAppRemoval and automatic Date & Time), because those are enforced only while GoldTime holds Screen Time authorization. After that, everything returns to normal immediately.

If you have any questions about this feature, please contact us — thank you for the review.
```
