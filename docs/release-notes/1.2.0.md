# 1.2.0 릴리스 노트

App Store Connect "이번 버전의 새로운 기능"에 붙여넣는 원문. 대상 범위는 `1.1.2..1.2.0`.

핵심 변경: 요일별 제한 규칙(요일마다 다른 규칙 + 주간 스트립), 규칙 편집 광고 게이트를
"진입"에서 "변경 완료" 시점으로 이동, 요일 트리거 알림.

---

## 한국어 (ko)

```
요일별 제한 규칙이 생겼습니다.

• 요일마다 다른 규칙 — 그룹마다 요일별로 일일 한도, 시간대 차단, 쿨다운, 제한 없음을 따로 정할 수 있어요. 평일엔 조이고 주말엔 풀어주는 식으로요.
• 한 주가 한눈에 — 7일 규칙을 주간 스트립으로 보여줍니다. 오늘이 어떤 규칙인지 바로 보이고, 요일을 탭하면 그 자리에서 편집됩니다.
• 규칙 구경은 무료 — 규칙을 열어보고 확인하는 데는 이제 광고가 없습니다. 광고는 실제로 규칙을 바꿀 때만 나옵니다.
• 알림도 요일을 따릅니다 — 사용량·차단 알림이 그날의 규칙에 맞춰 옵니다.

시간이 금이라는 거, 아직 잊지 않으셨죠.
```

## English (en)

```
Weekday rules are here.

• A different rule for each day — Set a daily limit, blocked time windows, a cooldown, or no limit at all, per weekday, for each group. Strict on weekdays, loose on Saturday. Your call.
• See the whole week — A 7-day strip shows which rule each day gets, with today highlighted. Tap a day to edit it right there.
• Browsing your rules is free — Opening and reviewing rules no longer costs you an ad. Ads only show up when you actually change one.
• Notifications follow the day — Usage and block alerts match whichever rule today is running.

Time is money. You still remember that, right?
```

## 日本語 (ja)

```
曜日ごとの制限ルールを追加しました。

• 曜日ごとに違うルール — グループごとに、1日の上限・時間帯ブロック・クールダウン・制限なしを曜日別に設定できます。平日は厳しく、週末はゆるく、というように。
• 1週間がひと目で — 7日分のルールを週間ストリップで表示します。今日がどのルールかすぐにわかり、曜日をタップすればその場で編集できます。
• ルールを見るのは無料 — ルールを開いて確認するだけなら、広告は表示されません。広告が出るのは、実際にルールを変更するときだけです。
• 通知も曜日に合わせて — 使用量・ブロックの通知が、その日のルールに合わせて届きます。

時間はお金です。まだ忘れていませんよね。
```
