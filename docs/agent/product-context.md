# Product Context

Read when: 문구, 톤앤매너, UX 흐름, 화면의 감정적 판단을 해야 할 때.

Skip when: 순수 로직, project config, 테스트, Screen Time 런타임 흐름만 바꿀 때.

제품, 문구, 톤앤매너, UX 판단이 필요할 때 읽습니다. 경쟁/유사 앱 패턴과 GoldTime다운 판단이 필요하면 `competitive-research.md`를 먼저 읽고, UI 구현, 공용 컴포넌트, 색상/Asset 판단이 필요하면 `ui-design-system.md`를 함께 봅니다.

## 앱 컨셉

GoldTime은 "시간이 금이다"라는 말에서 출발합니다. 사용자가 스크린타임 한도를 넘기면 Shield와 해제 선택지를 통해 계속 쓰는 행위를 비용처럼 느끼게 만듭니다.

GoldTime의 제품 정의는 "한도 초과 후 계속 쓰는 선택에 작은 비용을 붙여 무의식적 앱 사용을 의식적 선택으로 바꾸는 앱"입니다. 강한 차단보다 중요한 것은 사용자가 멈춘 자리에서 스스로 계산하게 만드는 것입니다.

핵심 농담은 적대적 조력자입니다.

```text
앱의 목표: 광고 많이 보여주기 -> 돈 벌기
유저의 목표: 광고 최대한 안 보기 -> 스크린타임 줄이기
결과: 유저가 이길수록 건강해짐
```

광고는 보상이 아니라 계속 쓰는 비용입니다. 사용자가 광고를 보지 않고 나가면 GoldTime은 돈을 못 번 척하지만, 제품적으로는 그 순간이 성공입니다.

## 제품 포지션

- Target platform: iOS 26.0+
- Bundle ID: `com.goldtime.app`
- Brand color: gold 계열.
- Color system: 실제 색상 토큰과 Asset Color 네이밍은 `ui-design-system.md`를 따릅니다.
- Tone: 냉소적이고 직설적이며 웃기지만, 결국 유저 편입니다.
- Positioning: 무의식적 사용에 통행료를 붙이는 Screen Time friction app.

경쟁 앱을 그대로 따라가지 않습니다. 경쟁/유사 앱의 세부 패턴은 `competitive-research.md`에서 판단하고, 이 문서는 GoldTime의 목소리와 화면 경험을 확정합니다.

## 목소리

GoldTime은 광고 수익을 원하는 척하지만, 유저가 광고를 안 보게 되는 게 더 좋은 일이라는 점이 드러나야 합니다.

톤 키워드:

- 건조함.
- 직설.
- 살짝 얄미움.
- 결국 사용자 편.

문장 공식:

```text
사실 1개 + 짧은 찌름 + 선택지
```

좋은 예:

- "오늘 저한테 ₩0 벌어줬어요"
- "또 왔어요?"
- "광고 보고 더 할 거예요? 진심으로요?"
- "시간이 금이라는 거 알죠?"
- "저는 기다릴게요. 당신이 결정하세요."
- "한도 끝났어요. 여기서 나가면 광고는 없습니다."
- "광고 안 보면 당신 승리예요. 저는 손해고요."
- "1분만 쓰는 사람은 보통 1분만 안 씁니다."
- "더 쓰려면 계산하세요."

피할 것:

- 평범한 웰니스 앱식 응원 문구.
- 설교하거나 수치심을 주는 문구.
- 모호한 AI식 동기부여 문구.
- 추정치나 농담인 광고 수익을 실제 수익처럼 보이게 하는 문구.
- 밈이나 유행어에 기대는 문구.
- 과한 악역 연기, 협박, 모욕, 중독자 낙인.
- "삶을 바꿔요", "당신은 할 수 있어요"처럼 감동을 요구하는 문구.
- 웃기려고 너무 긴 문구. Shield와 버튼에서는 특히 짧아야 합니다.

## UX 원칙

- 매일 쓰는 도구처럼 보여야 하며 랜딩 페이지처럼 보이면 안 됩니다.
- 대시보드는 반복해서 훑기 쉬워야 합니다.
- 해제 선택지는 명확하고 감정적으로 이해 가능해야 합니다.
- 핵심 선택을 가리는 장식을 추가하지 않습니다: 그만 쓰기, 기다리기, 제한된 1분 연장, 광고 보기.
- mock 값이나 추정치는 필요할 때 명확히 표시합니다.
- 웃긴 문구보다 선택의 명료함을 우선합니다.
- Shield는 가장 짧고 차갑게 말합니다. 농담은 한 문장만 허용합니다.
- Lock options는 사용자가 결제대 앞에 선 느낌이어야 합니다.
- Dashboard는 광고 수익보다 사용자가 광고를 피한 순간과 추가 사용 비용을 먼저 보여줍니다.

## UI 기본 원칙

- 특별한 지시가 없으면 기본 iOS 컴포넌트를 기반으로 HIG와 iOS 26.0 UI/UX에 자연스럽게 맞춥니다.
- UI 구현 규칙, 공용 컴포넌트 위치, Asset Color 규칙은 `ui-design-system.md`를 따릅니다.
- 웃긴 문구나 GoldTime다운 장치가 시스템 관성보다 앞서면 안 됩니다. 먼저 익숙하고 명확해야 합니다.

홈 화면 (Dashboard) 구성 — 현재 구현 기준:

- Hero 섹션 "오늘의 시간 청구서": 총 초과 사용 시간 (대형 숫자), 광고 개수, 남은 1분 연장 (N/N).
- 그룹 목록 섹션: 모니터링 상태, 그룹 카드 (그룹명, 상태 배지, 일일 한도, 앱 아이콘).

통계 화면 구성 — 현재 구현 기준:

1. StreakCard — 광고 없는 연속 일수 (현재/최대, adFreeStreakDays).
2. MetricGrid — 오늘 추가 사용 (delta caption 포함) + 이번 주 추가 사용 (delta caption 포함).
3. 주간 기록 — 7일 막대 차트, 이번 달 평균과 비교, 주 네비게이션.
4. 월간 기록 — 막대 차트, 전체 평균과 비교, 월 네비게이션.

화면별 톤:

- Onboarding: "조금 불편하게 만들겠다"는 약속을 명확히 설명합니다.
- Dashboard: 사용자가 GoldTime에게 돈을 벌어준 농담은 유지하되, 광고를 안 본 날이 더 좋은 날처럼 보여줍니다.
- Shield screen: 지금 막힌 이유와 다음 행동만 보여줍니다.
- Lock options: 1분, 광고, 그만 쓰기의 비용 차이를 즉시 이해하게 합니다.
- Ad screen: 광고 시청을 미화하지 않습니다. 더 쓰기 위해 치르는 비용으로 표현합니다.
- Stats screen: 어제·지난주와 비교해 "나빠지고 있는지, 잘 참고 있는지"를 차갑게 보여줍니다. 칭찬이나 응원 없이 숫자만 말합니다.

## 현재 제품 표면

- Onboarding: 인트로(앱 소개) → 스크린타임 권한 요청 → 알림 권한 요청 → 완료 (4단계, 앱 선택·한도 설정은 온보딩에 없음).
- Dashboard (HomeView): "오늘의 시간 청구서" Hero(총 초과 사용 시간, 광고 개수, 남은 1분 연장) + 그룹 목록 관리 섹션.
- Stats screen: 스트릭 카드, 오늘/주간 추가 사용 메트릭 그리드, 주간 기록 차트, 월간 기록 차트.
- Lock options: 그만 쓰기(강조색, 첫 번째) → 1분만 더 쓰기 → 광고 보고 10분 구매하기.
- Ad screen: 보상형 광고 표시와 fallback.
- Shield screen: 시스템 Shield 문구와 버튼.
