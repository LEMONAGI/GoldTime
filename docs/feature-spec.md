# GoldTime 기능 명세

현재 구현 기준: 2026-05-28

이 문서는 GoldTime의 기능을 사람이 읽기 좋게 정리한 제품 명세입니다. 코드 작업용 가이드가 아니라, 앱이 지금 어떤 화면과 규칙으로 동작하는지 빠르게 확인하기 위한 문서입니다.

## 1. 앱 한눈에 보기

GoldTime은 사용자가 직접 정한 앱/웹 사이트 사용 한도를 넘기면 iOS Screen Time Shield로 막고, 계속 쓰려는 선택에 작은 비용을 붙이는 앱입니다.

핵심 루프는 다음과 같습니다.

1. 사용자가 그룹을 만든다.
2. 그룹에 제한할 앱/웹 사이트와 일일 한도를 정한다.
3. GoldTime이 그룹별 사용 시간을 1분 단위로 추적한다.
4. 한도에 도달한 그룹은 Shield로 잠긴다.
5. 사용자는 그만 쓰거나, 하루 제한이 있는 1분 연장을 쓰거나, 광고를 보고 10분 연장한다.
6. 연장/광고/그만두기 기록은 홈과 통계에 반영된다.

GoldTime의 제품 톤은 "광고 수익을 원하는 척하지만, 사용자가 광고를 안 보고 나가면 더 성공"입니다.

## 2. 핵심 용어

| 용어 | 의미 |
| --- | --- |
| 그룹 | 함께 묶어서 관리하는 제한 대상 묶음. 앱과 웹 사이트를 담을 수 있다. |
| 제한 항목 | 그룹에 들어간 앱 또는 웹 사이트. |
| 일일 한도 | 해당 그룹을 하루에 사용할 수 있는 시간. 분 단위로 관리된다. |
| Shield | iOS가 제한 대상 앱/웹 사이트 위에 띄우는 차단 화면. |
| 잠금 중 | 그룹이 일일 한도에 도달해 Shield 대상이 된 상태. |
| 연장 중 | 잠긴 그룹이 1분 연장 또는 광고 연장으로 임시 해제된 상태. |
| 1분 연장 | 광고 없이 1분만 더 쓰는 선택지. 하루 5회 제한. |
| 광고 연장 | 보상형 광고 1회를 보고 특정 그룹을 10분 더 쓰는 선택지. |
| 추가 사용 시간 | 한도 초과 뒤 1분 연장과 광고 연장으로 얻은 시간의 합. |
| 광고 없는 연속 일수 | 광고를 보지 않은 날이 오늘까지 며칠 이어졌는지 나타내는 지표. |

## 3. 전역 구조

### 탭

앱 본체는 3개 탭으로 구성됩니다.

| 탭 | 역할 |
| --- | --- |
| 홈 | 오늘의 초과 사용 현황과 그룹 설정을 관리한다. |
| 통계 | 추가 사용 시간, 광고 없는 연속 일수, 주간/월간 기록을 본다. |
| 설정 | 권한 상태, 주 시작 요일, 스크린 타임 재연결을 관리한다. |

### 전역 스타일

- 앱은 다크 모드를 기본으로 사용한다.
- 기본 강조색은 gold 계열 `AccentColor`다.
- Screen Time 기능 특성상 주요 기능은 실기기에서 검증해야 한다.
- 광고 관련 기능은 Google Mobile Ads SDK와 보상형 광고 흐름을 사용한다.

## 4. 화면별 명세

## 4.1 온보딩

첫 실행 또는 필수 권한이 부족할 때 표시됩니다.

### 진입 조건

- 최초 홈 진입이 완료되지 않았고, 스크린 타임 권한 또는 알림 권한이 부족하면 온보딩을 표시한다.
- 최초 홈 진입 후 알림 권한만 빠진 경우에는 알림 권한 단계부터 표시한다.

### 단계

| 순서 | 화면 | 주요 내용 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | 인트로 | 앱 컨셉 소개. 한도를 넘기면 잠기고, 더 쓰려면 광고로 시간을 구매한다고 설명한다. | `시작하기` 탭 |
| 2 | 스크린타임 권한 | 앱 사용 시간 추적과 잠금을 위해 Screen Time 권한이 필요하다고 안내한다. | 권한 허용 |
| 3 | 알림 권한 | 한도 접근/앱 복귀 알림을 위해 알림 권한이 필요하다고 안내한다. | 알림 허용 |
| 4 | 맞춤 광고 허용 | 맞춤 광고 허용을 요청한다. 거부해도 광고는 계속 표시된다고 안내한다. | 계속 |
| 5 | 완료 | 준비 완료 메시지. | 홈 진입 |

### 예외 처리

- 스크린 타임 권한 요청이 실패하면 다시 허용하라는 오류 메시지를 보여준다.
- 알림 권한이 거부되면 iOS 설정에서 GoldTime 알림을 켜라고 안내하고, 설정 열기 버튼을 제공한다.
- 맞춤 광고 허용은 필수 사용 조건이 아니다.

## 4.2 홈

홈은 오늘 상태와 그룹 관리를 한 화면에서 처리합니다.

### 오늘의 시간 청구서

상단 Hero 영역입니다.

| 표시 항목 | 의미 |
| --- | --- |
| 총 초과 사용 시간 | 오늘 1분 연장과 광고 연장으로 얻은 시간의 합. 없으면 `0분`, 있으면 `+N분` 형식. |
| 광고 | 오늘 본 광고 개수. |
| 남은 1분 연장 | `남은 횟수/하루 제한` 형식. 현재 하루 제한은 5회. |
| 코멘트 | 총 초과 사용 시간 구간에 따라 GoldTime식 문구를 표시한다. |

### 그룹 목록

사용자가 Screen Time 제한 그룹을 관리하는 영역입니다.

| 기능 | 설명 |
| --- | --- |
| 그룹 수 표시 | `그룹 N/5` 형식으로 현재 그룹 수와 최대 그룹 수를 보여준다. |
| 자동 적용 상태 | 유효 그룹이 모니터링 중인지, 설정이 필요한지 보여준다. |
| 빈 상태 | 그룹이 없으면 그룹을 만들고 항목을 선택하라고 안내한다. |
| 그룹 추가 | 새 그룹을 만든다. 최대 5개까지 가능하다. |
| 제한 안내 | 그룹당 앱/웹 사이트 합계 9개까지 가능하다고 안내한다. 같은 항목을 여러 그룹에 포함시킬 수 있다. |

### 그룹 카드

각 그룹은 카드로 표시됩니다.

| 표시/동작 | 설명 |
| --- | --- |
| 그룹명 | 텍스트 필드로 바로 수정할 수 있다. 빈 이름은 내부적으로 `이름 없는 그룹`으로 표시된다. |
| 상태 배지 | `잠금 중`, `연장 중`, `설정 필요`, `적용 중`, `대기 중` 중 하나를 표시한다. |
| 재잠금 남은 시간 | 연장 중이면 `N분 뒤 재잠금` 형식으로 표시한다. |
| 잠금까지 남은 시간 | 유효 그룹이 아직 한도 안쪽이면 `N분 뒤 잠금` 형식으로 표시한다. |
| 일일 한도 | 현재 한도를 보여주고, 탭하면 한도 선택 시트를 연다. |
| 제한 항목 | 선택된 앱/웹 사이트 아이콘과 `N/9` 카운트를 보여준다. |
| 잠금 해제 | 잠긴 그룹에서만 표시된다. 탭하면 잠금 선택지 화면을 특정 그룹 기준으로 연다. |
| 삭제 | 그룹을 삭제한다. 잠긴 그룹은 광고 게이트를 거쳐야 한다. |

### 잠긴 그룹 편집 규칙

우회 방지를 위해 잠긴 그룹은 바로 편집하거나 삭제할 수 없습니다.

잠긴 그룹에서 다음 행동을 하면 광고 게이트가 먼저 뜹니다.

- 제한 항목 편집
- 일일 한도 변경
- 그룹 삭제

광고 게이트를 완료하면 원래 하려던 편집/삭제 작업이 이어집니다. 광고를 불러올 수 없으면 fallback 버튼으로 작업을 계속할 수 있습니다.

## 4.3 항목 선택 시트

그룹에 담을 앱/웹 사이트를 고르는 화면입니다.

| 항목 | 설명 |
| --- | --- |
| 선택 UI | iOS `FamilyActivityPicker`를 사용한다. |
| 저장 대상 | 앱 토큰과 웹 도메인 토큰만 저장한다. 카테고리 선택은 저장 시 제외된다. |
| 개수 제한 | 앱/웹 사이트 합계가 9개를 넘으면 경고를 표시하고 완료 버튼을 비활성화한다. |
| 웹 사이트 안내 | 웹 사이트는 Safari에서 사용할 때만 적용된다는 안내를 표시한다. |
| 완료 | 선택 내용을 그룹에 저장하고 모니터링 규칙을 다시 동기화한다. |

## 4.4 일일 한도 선택 시트

그룹의 일일 한도를 설정하는 시트입니다.

| 항목 | 설명 |
| --- | --- |
| 입력 방식 | 시간/분 wheel picker. |
| 시간 범위 | 0시간부터 6시간까지. |
| 분 단위 | 0분부터 55분까지 5분 간격. |
| 저장값 | `시간 * 60 + 분`을 일일 한도 분으로 저장한다. |
| 취소 | 변경 없이 닫는다. |

## 4.5 통계

통계는 "얼마나 더 썼는지"와 "광고를 얼마나 피했는지"를 보여줍니다.

### 상단 메트릭

| 카드 | 설명 |
| --- | --- |
| 광고 없는 연속 일수 | 현재 광고 없는 연속 일수와 최고 기록을 표시한다. |
| 추가 사용 | 오늘 추가 사용 시간을 표시하고 어제와 비교한다. |
| 이번 주 추가 사용 | 이번 주 추가 사용 시간을 표시하고 지난 주와 비교한다. |

### 주간 기록

| 기능 | 설명 |
| --- | --- |
| 주 이동 | 이전 주로 이동할 수 있다. 과거 주에서만 다음 주 버튼이 활성화된다. |
| 막대 차트 | 7일의 추가 사용 시간을 막대로 보여준다. |
| 빈 상태 | 추가 사용 기록이 없으면 `추가 사용 기록 없음`을 표시한다. |
| 평균 비교 | 주간 평균을 이번 달 평균과 비교한다. |
| 주 시작 요일 | 설정의 `주 시작 요일` 값에 따라 주간 범위가 달라진다. |

### 월간 기록

| 기능 | 설명 |
| --- | --- |
| 월 이동 | 이전 달로 이동할 수 있다. 과거 월에서만 다음 월 버튼이 활성화된다. |
| 막대 차트 | 해당 월의 일별 추가 사용 시간을 막대로 보여준다. |
| 빈 상태 | 추가 사용 기록이 없으면 `추가 사용 기록 없음`을 표시한다. |
| 평균 비교 | 월간 평균을 올해 평균 또는 해당 연도 평균과 비교한다. |

### 통계에 반영되는 값

| 값 | 증가 시점 |
| --- | --- |
| 광고 시청 수 | 광고 연장 성공 시 +1 |
| 광고 연장 시간 | 광고 연장 성공 시 +10분 |
| 1분 연장 사용 수 | 1분 연장 성공 시 +1 |
| Shield 도달 수 | 그룹이 한도에 도달해 Shield 대상이 될 때 +1 |
| 그만 쓰기 수 | Shield 또는 잠금 선택지에서 그만 쓰기를 선택할 때 +1 |

## 4.6 설정

설정은 권한과 문제 해결 중심입니다.

### 일반

| 항목 | 설명 |
| --- | --- |
| 스크린 타임 권한 | 허용 여부를 표시한다. 권한이 없으면 다시 요청할 수 있다. |
| GoldTime 복귀 알림 | 알림 권한 상태를 표시한다. 거부 상태면 iOS 앱 설정을 연다. |
| 주 시작 요일 | 통계의 주간 기준을 월요일 또는 일요일로 선택한다. 기본값은 월요일. |

### 문제 해결

| 항목 | 설명 |
| --- | --- |
| 스크린 타임 재연결 | DeviceActivity 모니터링 연결이 끊겼을 때 전체 모니터링을 다시 등록한다. 성공/실패 알림을 표시한다. |

## 4.7 스크린 타임 권한 복구 화면

최초 홈 진입 이후 스크린 타임 권한이 사라진 경우, 앱 본체 위에 전체 화면 복구 UI가 뜹니다.

| 항목 | 설명 |
| --- | --- |
| 제목 | `스크린타임 권한이 필요해요` |
| 설명 | 앱 한도를 적용하려면 권한을 다시 허용해야 한다고 안내한다. |
| 버튼 | `스크린타임 허용하기` |
| 닫기 | 권한 복구 전에는 사용자가 임의로 닫을 수 없다. |

## 4.8 Shield 화면

iOS가 제한 대상 앱/웹 사이트 위에 띄우는 차단 화면입니다.

### 기본 Shield

| 항목 | 설명 |
| --- | --- |
| 제목 | 짧은 GoldTime식 문구 중 하나를 무작위로 표시한다. |
| 부제 | `더 쓰려면 GoldTime에서 선택하세요.` |
| 기본 버튼 | `그만 쓰기` |
| 보조 버튼 | `GoldTime 열기` |

기본 버튼을 누르면 Shield가 닫히고 `그만 쓰기` 기록이 증가합니다.

보조 버튼을 누르면 익스텐션이 앱을 직접 열 수 없기 때문에 GoldTime 복귀 알림을 예약하고, 사용자가 알림을 눌러 앱으로 돌아오게 합니다.

### 앱 열기 요청 중 Shield

사용자가 `GoldTime 열기`를 누른 직후에는 Shield 문구가 바뀝니다.

| 항목 | 설명 |
| --- | --- |
| 제목 | `위의 GoldTime 알림을 눌러주세요` |
| 부제 | 알림이 오지 않으면 다시 알림 보내기 또는 방해금지 모드를 확인하라고 안내한다. |
| 기본 버튼 | `그만 쓰기` |
| 보조 버튼 | `다시 알림 보내기` |

## 4.9 잠금 선택지

Shield에서 GoldTime 복귀 알림을 누르거나, 홈의 잠긴 그룹에서 `잠금 해제`를 누르면 표시됩니다.

### 진입 맥락

- 특정 앱/웹 사이트에서 들어온 경우, 해당 항목이 포함된 잠긴 그룹을 우선 찾는다.
- 잠긴 그룹이 1개면 자동 선택한다.
- 잠긴 그룹이 여러 개면 사용자가 한 그룹을 고른다.
- 한 번에 한 그룹만 연장할 수 있다.

### 선택지

| 선택지 | 효과 | 제한 |
| --- | --- | --- |
| 그만 쓰기 | 잠금을 유지하고 화면을 닫는다. 광고 없음. | 잠긴 그룹이 있으면 그만 쓰기 기록이 증가한다. |
| 1분만 더 쓰기 | 선택한 그룹을 1분 연장한다. | 하루 5회까지. 선택 그룹이 필요하다. |
| 광고 보고 10분 구매하기 | 보상형 광고 후 선택한 그룹을 10분 연장한다. | 선택 그룹이 필요하다. |

### 연장 완료

연장이 성공하면 완료 알림을 표시합니다.

- 어떤 그룹을 몇 분 연장했는지 알려준다.
- 연장 시간이 지나면 다시 잠긴다고 안내한다.
- 같은 앱/웹 사이트가 다른 잠긴 그룹에도 포함되어 있으면, 아직 잠긴 그룹이 남았다고 알려준다.

### 재잠금 타이머 실패

연장은 항상 "해제 후 다시 잠금"이 보장되어야 합니다. 재잠금 타이머 등록에 실패하면 잠금을 유지하고 자동 재시도를 시작합니다.

- 화면에 실패 메시지를 표시한다.
- 짧은 간격으로 자동 재시도한다.
- 사용자가 `다시 시도`를 직접 누를 수도 있다.

## 4.10 보상형 광고 화면

광고 연장 또는 잠긴 그룹 편집 게이트에서 사용합니다.

| 상태 | 표시/동작 |
| --- | --- |
| 광고 준비 중 | 검은 배경, `광고 준비 중`, ProgressView, 취소 버튼을 표시한다. |
| 광고 표시 가능 | 보상형 광고를 자동 표시한다. |
| 광고 성공 | 호출한 흐름의 완료 콜백을 실행한다. 잠금 선택지에서는 10분 연장, 편집 게이트에서는 원래 작업 수행. |
| 광고 취소/보상 없음 | 호출한 흐름의 취소 콜백을 실행한다. |
| 광고 로드 실패 | fallback 화면을 보여준다. 사용자가 fallback 버튼을 누르면 완료 처리한다. |

## 5. 기능별 명세

## 5.1 그룹 관리

### 제한

| 규칙 | 현재값 |
| --- | --- |
| 최대 그룹 수 | 5개 |
| 그룹당 제한 항목 수 | 앱/웹 사이트 합계 9개 |
| 전체 Shield 앱 수 제한 | 앱 토큰 union 기준 49개 |
| 기본 그룹명 | `그룹 1`, `그룹 2` ... |
| 기본 일일 한도 | 30분 |

### 유효 그룹 조건

다음 조건을 만족하는 그룹만 자동 모니터링 대상이 됩니다.

- 앱 또는 웹 사이트가 1개 이상 있다.
- 일일 한도가 0분 이상이다.
- 앱/웹 사이트 합계가 9개 이하이다.
- 카테고리 토큰이 남아 있지 않다.

현재 저장 과정에서는 앱/웹 사이트 토큰만 남기므로 카테고리 선택은 실질적으로 제한 대상에서 제외됩니다.

## 5.2 자동 모니터링

GoldTime은 유효한 그룹마다 독립적인 DeviceActivity 모니터링을 등록합니다.

### 동작 방식

- 하루 단위 스케줄은 00:00부터 23:59까지 반복된다.
- 각 그룹은 1분 threshold 이벤트로 사용 시간을 누적한다.
- threshold에 도달할 때마다 해당 그룹의 사용 시간이 1분 증가한다.
- 사용 시간이 그룹의 일일 한도 이상이면 그룹을 잠금 상태로 표시하고 Shield를 적용한다.
- 아직 한도 미만이면 동일 그룹 모니터링을 재등록해 다음 1분을 다시 센다.

### 동기화 시점

- 앱 실행/활성화 시.
- 그룹 추가/삭제/이름 변경/한도 변경/항목 변경 후.
- 설정의 스크린 타임 재연결 실행 시.
- 연장 만료 여부를 확인하는 홈의 주기적 refresh 시.

## 5.3 Shield 적용

### 적용 대상

잠긴 그룹들의 앱 토큰과 웹 도메인 토큰을 합쳐 하나의 Shield union으로 적용합니다.

### 그룹별 상태

| 상태 | 의미 |
| --- | --- |
| 적용 중 | 유효 그룹이고 모니터링 중이며 아직 잠기지 않았다. |
| 대기 중 | 유효 그룹이지만 모니터링이 아직 준비/동기화 중이다. |
| 설정 필요 | 제한 항목이나 한도 조건이 부족해 모니터링 대상이 아니다. |
| 잠금 중 | 한도에 도달해 Shield 대상이다. |
| 연장 중 | 잠긴 그룹이 임시 해제되어 재잠금 시간을 기다리는 중이다. |

## 5.4 연장

### 1분 연장

- 선택한 잠긴 그룹만 60초 동안 임시 해제한다.
- 하루 5회까지 사용할 수 있다.
- 성공 시 오늘 1분 연장 사용 수가 증가한다.
- 홈의 `남은 1분 연장`이 즉시 갱신된다.

### 광고 연장

- 보상형 광고를 완료하면 선택한 잠긴 그룹만 10분 동안 임시 해제한다.
- 성공 시 오늘 광고 개수와 광고 연장 시간이 증가한다.
- 광고 로드 실패 시 fallback 버튼으로 완료 처리할 수 있다.

### 재잠금

- 연장할 때 해당 그룹에 대한 override 모니터링을 등록한다.
- override 시간이 끝나면 해당 그룹의 임시 해제를 해제하고 Shield를 다시 적용한다.
- 다른 잠긴 그룹은 연장 중인 그룹과 별개로 계속 잠겨 있을 수 있다.

## 5.5 일일 리셋

날짜가 바뀌면 다음 상태를 초기화합니다.

- 1분 연장 사용 횟수
- Shield 활성 상태
- 잠긴 그룹 목록
- 연장 상태
- 마지막 잠금 해제 요청 토큰
- Shield 열기 요청
- 그룹별 사용 시간
- 마지막 등록 그룹 기록

일별 통계는 유지됩니다.

## 5.6 통계

### 일별 저장 값

| 값 | 설명 |
| --- | --- |
| `adWatchCount` | 광고를 보고 연장한 횟수. |
| `adUnlockedSeconds` | 광고로 얻은 추가 사용 시간. |
| `oneMinuteUsedCount` | 1분 연장 사용 횟수. |
| `shieldHitCount` | Shield에 도달한 횟수. |
| `walkAwayCount` | 그만 쓰기를 선택한 횟수. |

### 계산 값

| 값 | 계산 |
| --- | --- |
| 총 추가 사용 시간 | `adUnlockedSeconds + oneMinuteUsedCount * 60` |
| 예상 광고 수익 | `adWatchCount * 100원` |
| 오늘 비교 | 오늘 추가 사용 시간 - 어제 추가 사용 시간 |
| 주간 비교 | 이번 주 추가 사용 시간 - 지난 주 추가 사용 시간 |
| 광고 없는 연속 일수 | 오늘부터 과거로 보며 광고 수가 0인 날의 연속 길이 |
| 최고 광고 없는 연속 일수 | 기록 시작일부터 현재까지 광고 수 0인 연속 구간의 최댓값 |

예상 광고 수익은 제품 농담과 내부 표시용 추정치이며 실제 정산 금액으로 취급하지 않습니다.

## 5.7 권한

### 필수 권한

| 권한 | 필수 여부 | 이유 |
| --- | --- | --- |
| Screen Time / Family Controls | 필수 | 앱/웹 사이트 선택, 사용 시간 추적, Shield 적용에 필요하다. |
| 알림 | 사실상 필수 | Shield Action Extension에서 앱을 직접 열 수 없으므로 GoldTime 복귀 알림에 필요하다. |
| 앱 추적 투명성 | 선택 | 맞춤 광고 품질을 위한 흐름이며 거부해도 앱 사용 자체는 계속 가능하다. |

### 권한이 없어졌을 때

- Screen Time 권한이 없어지면 권한 복구 화면을 띄운다.
- 알림 권한이 없으면 온보딩 또는 설정에서 다시 안내한다.

## 5.8 금고 모드 (기간 약정 강력 잠금)

> 상태: 구현 완료(2026-07-13, `Feat/AbsoluteLock`) — **실기기 검증 대기**
> (런북: [verify-strictlock-runbook](verify-strictlock-runbook.md), 검증 완료 전 제출 금지).
> 결정 근거·트레이드오프는 `docs/agent/decision-context.md`의 ADR 참조. UI 명칭 "금고 모드".

### 개념

- 그룹별 opt-in 자기 약정 모드. 규칙 집행은 평소대로 굴러가고(자정 리셋·요일 전환·쿨다운
  재충전 포함), **도망갈 문(연장·규칙 편집·삭제)만 약정 기간 동안 잠근다**.
- 켤 때 기간을 고르고, **중도 해제는 어떤 수단으로도 불가**하다. 만료 시 자동 해제된다.
- 긴급 탈출구는 의도적으로 없다(Opal식 Emergency Pass 미도입).

### 약정 기간

- 프리셋 1일 / 3일 / 7일 / 14일 (상한 14일 — 실수 보호).
- 만료 시각은 항상 자정 경계: N일 약정 = 오늘 포함 N일, 만료 = 마지막 날 다음 0시.
  예: 7/12에 3일 → 7/15 00:00 해제. "모든 잠금은 하루 단위" 주기와 일치한다.
- 약정 중 기간 추가(연장)는 허용, 축소는 불가(강화 방향만).

### 켜기 조건·흐름

- applied + 유효 규칙(invalidReason 없음) 그룹만 켤 수 있다. draft 불가.
- 흐름: 그룹 카드 → 금고 모드 진입 → 기간 선택 → 고지 화면 → 강한 확인(2단계).
- 고지 화면 5행 + 그룹 재확인. **주 문장은 사용자가 겪는 결과, 수단·부작용은 각주로 내린다**
  (수단을 앞세우면 "왜 날짜를 건드리지?" 같은 의심이 먼저 온다):
  ① 중도 해제 불가 ② 규칙 변경·삭제 잠금 ③ 1분·광고 연장 잠금
  ④ "GoldTime 앱을 삭제할 수 없어요" — 각주: iOS 제약이라 이 기간엔 기기의 다른 앱 삭제도
  함께 막힌다(고지 의무) ⑤ "시간을 돌려서 해제할 수 없어요" — 각주: 날짜·시간이 자동 고정된다.
- **켜기 화면에서 "권한을 끄면 풀린다"는 안내는 하지 않는다**(2026-07-13 결정). 사실이지만
  잠그려는 순간에 탈출 방법을 알려주는 셈이라 모드의 목적을 스스로 무너뜨린다. 권한 철회는
  이미 풀린 뒤(복구 화면)에만 다룬다 — 아래 "권한 철회" 절.
- **켜기는 무료**(광고 없음) — "강화는 무료, 완화에 통행료" 철학 유지.

### 약정 중 잠기는 것

| 표면 | 동작 |
| --- | --- |
| 1분 연장·광고 연장 | 거부. 쿨다운 **휴식 중 해제(건너뛰기)** 포함 — 쿨다운 ADR("휴식도 비용을 치르면 풀 수 있다")의 의도된 예외. **휴식 자체는 평소대로 시간이 지나면 끝나고 예산이 재충전된다**(집행 규칙은 금고와 무관 — 금고는 "돈으로 건너뛰기"만 막는다). |
| 규칙 편집 | 전면 차단(강화 방향 포함 — 판별 없이 단순 차단). 진입 시 만료일 안내. |
| 그룹 삭제 | 차단. 만료일 안내. |
| 기기 앱 삭제 | `denyAppRemoval` — **기기 전체** 앱 삭제가 막힌다(Apple 제약, 전역). |
| 수동 날짜·시간 변경 | `requireAutomaticDateAndTime` — 시계를 내일로 돌려 자정 리셋을 발화시키는 우회 봉쇄. |

### 잠기지 않는 것

- 규칙 자체의 집행(자정 리셋, 요일별 규칙 전환, **쿨다운 휴식 종료·예산 재충전** 전부 평소대로).
  → 5분 쓰고 30분 휴식이면 30분 뒤 정상적으로 풀린다. 금고는 그 30분을 **광고로 건너뛰는 것**만
  막는다. 재충전 경로(`endCooldownAndRecharge`/`handleCooldownTimerEnded`/
  `rechargeExpiredCooldowns`)에 strict guard를 넣으면 휴식이 영영 안 끝난다 — 넣지 말 것
  (회귀 테스트 `cooldownRestStillEndsAndRechargesDuringStrictLock`가 고정).
- 다른 그룹의 편집·연장·삭제, 새 그룹 생성, 통계·설정 화면.

### 약정 중 표시

- 그룹 카드에 금고 배지 + D-N(만료일).
- Shield "GoldTime 가기" → 잠금 선택지 화면에서 연장 버튼 대신 "금고 모드 — 만료일" 안내.

### 권한 철회 (수용하는 구멍)

- Screen Time 권한 철회 시 Shield·denyAppRemoval이 모두 풀린다(Apple 제약 — 어떤 앱도
  API로 못 막는다). 스크린타임 암호 안내 방식은 검토 후 제외했다(2026-07-12 사용자 결정).
- **켜기 화면에서는 이 구멍을 안내하지 않는다**(위 참조). 대응은 사후에만: 미승인 + 약정 활성
  감지 시 복구 화면에 약정 상태 강조·재승인 유도(`recovery.strictNotice`), `strict_revoke_detected`
  분석 이벤트 기록.
- 약정은 SharedStore에 보존되어 재승인 시 그대로 복원된다(철회로 약정이 리셋되지 않는다).

### 만료

- 만료 후 첫 동기화에서 자연 복귀(별도 상태 전환 이벤트 없음 — 판정은 항상 `strictUntil > now`).
- 약정 활성 그룹이 0개가 되면 전역 설정(denyAppRemoval·자동 날짜 강제)을 해제한다.
  자정 만료는 DeviceActivityMonitorExtension의 자정 재무장에서도 재평가한다.
- 완주 축하·재약정 제안은 선택 사항.

## 6. 현재 주의할 점

- 웹 사이트 제한은 Safari 사용 맥락에서만 적용된다고 안내한다.
- 카테고리 제한은 저장 대상에서 제외된다.
- 시뮬레이터만으로 Screen Time, Shield, FamilyControls 흐름을 완료 검증할 수 없다.
- Shield에서 앱을 직접 여는 것은 불가능하므로 알림을 통해 앱 복귀를 유도한다.
- 잠긴 그룹의 편집/삭제는 우회 방지를 위해 광고 게이트를 통과해야 한다.
- 여러 그룹에 같은 앱이 들어갈 수 있고, 한 앱이 여러 잠긴 그룹에 걸리면 한 그룹만 연장해도 다른 그룹 때문에 계속 잠겨 있을 수 있다.
