# GoldTime 기능 명세

현재 구현 기준: 2026-08-07

이 문서는 GoldTime의 기능을 사람이 읽기 좋게 정리한 제품 명세입니다. 코드 작업용 가이드가 아니라,
앱이 지금 어떤 화면과 규칙으로 동작하는지 빠르게 확인하기 위한 문서입니다.
문서와 코드가 다르면 **코드가 진실**입니다.

---

## 1. 앱 한눈에 보기

GoldTime은 사용자가 직접 정한 앱/웹 사이트 사용 규칙을 넘기면 iOS Screen Time Shield로 막고,
계속 쓰려는 선택에 작은 비용을 붙이는 앱입니다.

핵심 루프는 다음과 같습니다.

1. 사용자가 그룹을 만든다.
2. 그룹에 제한할 앱/웹 사이트를 담고, **차단 규칙**(일일 한도 / 시간대별 차단 / 쿨다운 잠금,
   또는 요일별 조합)을 고른다.
3. `적용하기`를 누르면 그때부터 GoldTime이 그 그룹을 추적·집행한다.
4. 규칙을 넘긴 그룹은 Shield로 잠긴다.
5. 사용자는 그만 쓰거나, 하루 제한이 있는 1분 연장을 쓰거나, 광고를 보고 10분 연장한다.
6. 연장/광고/그만두기 기록은 홈과 통계에 반영된다.

GoldTime의 제품 톤은 "광고 수익을 원하는 척하지만, 사용자가 광고를 안 보고 나가면 더 성공"입니다.

## 2. 핵심 용어

| 용어 | 의미 |
| --- | --- |
| 그룹 | 함께 묶어서 관리하는 제한 대상 묶음. 앱과 웹 사이트를 담을 수 있다. |
| 제한 항목 | 그룹에 들어간 앱 또는 웹 사이트. |
| 차단 규칙 | 그룹이 언제 잠기는지 정하는 규칙. 일일 한도 / 시간대별 차단 / 쿨다운 잠금 3종 + 요일별 조합. |
| 적용(apply) | 그룹의 보호를 시작시키는 확정 행위. 적용 전(draft)에는 추적도 잠금도 없다. |
| Shield | iOS가 제한 대상 앱/웹 사이트 위에 띄우는 차단 화면. |
| 잠금 중 | 그룹이 규칙에 걸려 Shield 대상이 된 상태. |
| 추가 사용 중 | 잠긴 그룹이 1분 연장 또는 광고 연장으로 임시 해제된 상태(override). |
| 1분 연장 | 광고 없이 1분만 더 쓰는 선택지. 하루 5회 제한. |
| 광고 연장 | 보상형 광고 1회를 보고 특정 그룹을 10분 더 쓰는 선택지. |
| 광고 게이트 | 적용된 그룹을 편집·삭제할 때 통과해야 하는 보상형 광고 관문. |
| 연장 불가 모드 | 정한 기간 동안 연장·편집·삭제를 스스로 봉인하는 opt-in 모드. |
| 추가 사용 시간 | 1분 연장과 광고 연장으로 얻은 시간의 합. |
| 광고 없는 연속 일수 | 광고를 보지 않은 날이 오늘까지 며칠 이어졌는지 나타내는 지표. |

## 3. 전역 구조

### 탭

앱 본체는 3개 탭으로 구성됩니다.

| 탭 | 역할 |
| --- | --- |
| 홈 | 오늘의 초과 사용 현황과 그룹·규칙을 관리한다. |
| 통계 | 추가 사용 시간, 광고 없는 연속 일수, 주간/월간 기록을 본다. |
| 설정 | 권한·알림·연장 불가 모드·주 시작 요일·문제 해결·피드백·개인정보를 관리한다. |

### 전역 스타일·전제

- 앱은 다크 모드를 기본으로 사용한다.
- 기본 강조색은 gold 계열 `AccentColor`이며, 색은 전부 Asset Color로 관리한다.
- 한국어/영어/일본어 3개 언어를 지원한다(일본어는 です·ます체).
- Screen Time 기능 특성상 주요 기능은 실기기에서 검증해야 한다.
- 광고는 Google Mobile Ads SDK 보상형 광고 + UMP 동의 흐름을 사용한다.

## 4. 차단 규칙 (제품의 중심)

그룹마다 **차단 규칙 1종**을 고르거나, **요일별 규칙**으로 요일마다 다른 규칙을 걸 수 있습니다.
규칙 편집은 그룹 카드 → `차단 규칙` 행에서 열리는 규칙 편집 시트에서 합니다.

### 4.1 일일 한도 제한

> "하루에 정한 시간을 넘기면 잠겨요"

| 항목 | 값 |
| --- | --- |
| 입력 | 시간/분 wheel picker |
| 시간 범위 | 0시간 ~ 5시간 |
| 분 단위 | 0분 ~ 55분, 5분 간격 |
| 저장값 | `시간 * 60 + 분` (분 단위) |

- 1분 threshold 이벤트로 사용 시간을 누적하고, 한도에 도달하면 잠근다.
- 잠금은 그날 23:59까지 유지되고 자정에 리셋된다.

### 4.2 시간대별 차단

> "정한 시간대 동안 사용을 막아요"

| 규칙 | 값 |
| --- | --- |
| 시간대 개수 | 그룹당 최대 3개 |
| 최소 길이 | 15분 (DeviceActivitySchedule이 15분 미만 interval을 거부한다) |
| 자정 넘김 | 금지 (시작 ≤ 종료) |
| 겹침 | 금지 |

- 시간대가 시작되면 잠기고, 종료되면 자동으로 풀린다.
- 연속된 시간대가 이어져 있으면 마지막 종료 시각까지 잠금으로 표시한다.

### 4.3 쿨다운 잠금

> "정한 만큼 쓰면 한동안 쉬어야 해요"

| 규칙 | 범위 |
| --- | --- |
| 사용 예산 | 5분 ~ 120분 |
| 강제 휴식 | 30분 ~ 360분 |

- 사용 예산을 다 쓰면 휴식(잠금)에 들어가고, 휴식이 끝나면 예산이 **재충전**되어 다시 쓸 수 있다.
- 휴식 종료·재충전은 GoldTime을 열지 않아도 extension이 처리한다.
- 휴식 시간을 광고/1분 연장으로 **건너뛸 수 있다**(비용을 치르면 휴식을 앞당길 수 있다는 결정).
  단 연장 불가 기간 중에는 건너뛰기가 막힌다(§7 참조).

### 4.4 요일별 규칙

> "요일마다 다른 규칙을 정할 수 있어요"

- 규칙 편집 시트의 `요일별 규칙` 토글을 켜면 요일 7개 각각에
  `제한 없음 / 일일 한도 제한 / 시간대별 차단 / 쿨다운 잠금` 중 하나를 배정한다.
- 편집은 **요일 묶음** 단위다. 여러 요일을 함께 골라 같은 규칙을 준다.
- 7일 전부 "제한 없음"이면 무효(적용할 규칙이 없다).
- 개별 요일의 유효성 검증은 위 규칙 3종의 정책을 그대로 따른다.
- 오늘 요일의 규칙이 그날의 집행 규칙이 되고, 자정에 다음 요일 규칙으로 전환된다.
- 오늘이 "제한 없음"인 그룹은 홈에서 `23:59까지 사용 가능`으로 표시된다.

## 5. 화면별 명세

### 5.1 온보딩

첫 실행 또는 필수 권한이 부족할 때 표시됩니다.

#### 진입 조건

- 최초 홈 진입이 완료되지 않았고, 스크린 타임 권한 또는 알림 권한이 부족하면 온보딩을 표시한다.
- 최초 홈 진입 후 알림 권한만 빠진 경우에는 알림 권한 단계부터 표시한다.

#### 단계

| 순서 | 화면 | 주요 내용 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | 인트로 | 앱 컨셉 소개. 한도를 넘기면 잠기고, 더 쓰려면 광고로 시간을 구매한다고 설명한다. | `시작하기` 탭 |
| 2 | 스크린타임 권한 | 앱 사용 시간 추적과 잠금을 위해 Screen Time 권한이 필요하다고 안내한다. | 권한 허용 |
| 3 | 알림 권한 | 한도 접근/앱 복귀 알림을 위해 알림 권한이 필요하다고 안내한다. | 알림 허용 |
| 4 | 맞춤 광고 허용 | 맞춤 광고 허용(ATT)을 요청한다. 거부해도 광고는 계속 표시된다고 안내한다. | 계속 |
| 5 | 완료 | 준비 완료 메시지. | 홈 진입 |

각 권한 단계에는 iOS 시스템 다이얼로그가 어떻게 생겼는지 미리 보여주는 안내 일러스트가 붙습니다.

#### 예외 처리

- 스크린 타임 권한 요청이 실패하면 다시 허용하라는 오류 메시지를 보여준다.
- 알림 권한이 거부되면 iOS 설정에서 GoldTime 알림을 켜라고 안내하고, 설정 열기 버튼을 제공한다.
- 맞춤 광고 허용은 필수 사용 조건이 아니다.

### 5.2 홈

홈은 오늘 상태와 그룹 관리를 한 화면에서 처리합니다.

#### 오늘의 시간 청구서

상단 Hero 영역입니다.

| 표시 항목 | 의미 |
| --- | --- |
| 총 초과 사용 시간 | 오늘 1분 연장과 광고 연장으로 얻은 시간의 합. 없으면 `0분`, 있으면 `+N분` 형식. |
| 광고 | 오늘 본 광고 개수. |
| 남은 1분 연장 | `남은 횟수/하루 제한` 형식. 하루 제한은 5회. |
| 코멘트 | 총 초과 사용 시간 구간에 따라 GoldTime식 문구를 표시한다("계산서 나왔어요. 확인해보실래요?"). |

#### 그룹 목록

| 기능 | 설명 |
| --- | --- |
| 그룹 수 표시 | `그룹 N/5` 형식. |
| 자동 적용 상태 | 적용된 그룹이 모니터링 중인지, 설정이 필요한지 보여준다. |
| 빈 상태 | 그룹이 없으면 그룹을 만들고 항목을 선택하라고 안내한다. |
| 그룹 추가 | 새 그룹을 만든다. 최대 5개. |
| 제한 안내 | 그룹당 앱/웹 사이트 합계 9개까지. 같은 항목을 여러 그룹에 포함시킬 수 있다. |

#### 그룹 카드

| 표시/동작 | 설명 |
| --- | --- |
| 그룹명 | 텍스트 필드로 바로 수정할 수 있다. 집행과 무관해 항상 수정 가능하다. |
| 상태 배지 | 아래 "상태 배지 문구" 표 참조. 아이콘·색(주황/초록/빨강/파랑)이 함께 바뀐다. |
| 남은 시간 바 | 일일 한도·쿨다운 그룹에서 잔여 시간을 10칸 블록 바로 보여준다. |
| 차단 규칙 | 현재 규칙 요약을 보여주고, 탭하면 규칙 편집 시트를 연다. |
| 제한 항목 | 선택된 앱/웹 사이트 아이콘과 `N/9` 카운트. 탭하면 항목 선택 시트를 연다. |
| 연장 불가 행 | 설정에서 연장 불가 모드를 켰고 적용된 그룹일 때만 표시된다. |
| 추가 사용 | 잠긴 그룹에서만 표시된다. 탭하면 잠금 선택지 화면을 그 그룹 기준으로 연다. |
| 적용하기 | 아직 적용 전(draft)인 그룹에만 표시된다. |
| 삭제 | 적용된 그룹은 광고 게이트를 거친다. draft는 확인 후 바로 삭제된다. |

#### 상태 배지 문구

| 상태 | 문구 | 조건 |
| --- | --- | --- |
| 설정 필요 | `설정 필요` | 아직 적용 전이거나, 규칙/항목 조건이 부족하다. |
| 대기 중 | `대기 중` | 적용됐지만 모니터링이 아직 준비/동기화 중이다. |
| 사용 가능 | `사용 가능` / `HH:mm까지 사용 가능` | 적용 중이고 아직 안 잠겼다. 시간대 규칙은 다음 차단 시작 직전 시각을 보여준다. |
| 제한 없는 요일 | `23:59까지 사용 가능` | 요일별 규칙에서 오늘이 "제한 없음"이다. |
| 잠금 중 | `23:59까지 잠금`(일일 한도) / `HH:mm까지 잠금`(쿨다운 휴식 종료·시간대 종료) | 규칙에 걸려 Shield 대상이다. |
| 추가 사용 중 | `N분 추가 사용` / `HH:mm까지 추가 사용` | 연장으로 임시 해제됐다. 자정 직전 광고 연장은 시각 표기를 쓴다. |
| 연장 불가 | `🔒 N일 남음` | 연장 불가 기간이 진행 중이다(상태 배지와 별도 배지). |

#### 적용(apply) 흐름

- 규칙과 제한 항목이 모두 갖춰져야 `적용하기` 버튼이 활성화된다. 부족하면 무엇이 빠졌는지
  캡션으로 알려준다("차단 규칙을 먼저 골라 주세요").
- 적용 전 확인 alert: *"‘그룹명’에 지금부터 적용돼요. 이후 규칙이나 항목을 바꾸거나 삭제하려면
  광고를 봐야 해요."*
- 적용 전(draft) 그룹은 추적·잠금 대상이 아니며, 자유롭게 편집·삭제할 수 있다.

#### 즉시 잠금 경고

이미 쓴 시간이 새 규칙을 이미 넘긴 경우(예: 오늘 40분 썼는데 한도를 30분으로 낮춤),
변경을 확정하기 전에 "지금 바로 잠긴다"는 경고 alert를 띄우고 `변경` / `취소`를 묻습니다.
일일 한도와 쿨다운 예산 각각에 대해 판정합니다.

#### 연장 불가 모드 무료 베타 안내

연장 불가 모드가 무료 베타로 나가는 버전에서는 홈 진입 시 안내 팝업을 띄웁니다.
`설정에서 확인`을 누르면 설정 탭으로 이동합니다.

### 5.3 항목 선택 시트

| 항목 | 설명 |
| --- | --- |
| 선택 UI | iOS `FamilyActivityPicker`를 사용한다. |
| 저장 대상 | 앱 토큰과 웹 도메인 토큰만 저장한다. 카테고리 선택은 저장 시 제외된다. |
| 개수 제한 | 앱/웹 사이트 합계가 9개를 넘으면 경고를 표시하고 완료 버튼을 비활성화한다. |
| 웹 사이트 안내 | 웹 사이트는 Safari에서 사용할 때만 적용된다는 안내를 표시한다. |
| 완료 | 선택 내용을 그룹에 저장하고 모니터링 규칙을 다시 동기화한다. |

### 5.4 규칙 편집 시트

| 영역 | 설명 |
| --- | --- |
| 요일별 규칙 토글 | 켜면 요일 묶음 편집 UI로, 끄면 단일 규칙 선택 UI로 전환된다. |
| 규칙 선택 | `일일 한도 제한` / `시간대별 차단` / `쿨다운 잠금` 중 하나를 고르고 상세 값을 입력한다. |
| 일일 한도 상세 | 시간/분 휠. |
| 시간대 상세 | 시작·종료 시각 DatePicker를 최대 3개까지 추가/삭제. |
| 쿨다운 상세 | 사용 예산·강제 휴식 휠. |
| 요일 묶음 편집 | 요일 칩으로 대상 요일을 고르고 규칙 종류·값을 지정한다. 오늘 요일은 별도로 표시된다. |
| 푸터 안내 | "이미 규칙이 적용된 그룹은 변경된 규칙도 바로 반영돼요." |
| 완료 | 적용된 그룹이고 **집행에 영향 있는 변경**이면 광고 게이트를 거친 뒤 저장한다(§6.5). |

### 5.7 알림 설정

| 알림 | 설명 | 끌 수 있나 |
| --- | --- | --- |
| 하루 요약 알림 | 매일 아침 9시에 어제 쓴 시간을 정리해 보낸다. 주 시작일에는 주간 통계로 대체된다. | 가능 |
| 사용·차단 알림 | 한도에 가까워지거나(50%·90%), 차단 직전(시간대 5분 전)·해제 시(쿨다운 재충전, 시간대 종료) 알린다. | 가능 |
| 앱 복귀 알림 | Shield에서 GoldTime으로 돌아오기 위한 알림. 기능상 필수라 끌 수 없다. | 불가 |

- 사용·차단 알림은 시간에 민감한 알림(`.timeSensitive`)으로 보내 집중 모드에서도 즉시 전달되게 한다.
- 요일별 그룹의 시간대 알림은 주간 7일치를 미리 쌓지 않고, 오늘 것 + 내일 자정 직후 시작분만
  날짜 포함 일회성으로 예약해 iOS의 pending 알림 상한(64개)을 넘기지 않는다.

### 5.8 스크린 타임 권한 복구 화면

최초 홈 진입 이후 스크린 타임 권한이 사라진 경우, 앱 본체 위에 전체 화면 복구 UI가 뜹니다.

| 항목 | 설명 |
| --- | --- |
| 제목 | `스크린타임 권한이 필요해요` |
| 설명 | 앱 한도를 적용하려면 권한을 다시 허용해야 한다고 안내한다. |
| 버튼 | `스크린타임 허용하기` |
| 연장 불가 안내 | 연장 불가 기간이 활성인 채 권한이 철회된 경우, 그 상태를 강조해 재승인을 유도한다. |
| 닫기 | 권한 복구 전에는 사용자가 임의로 닫을 수 없다. |

### 5.9 Shield 화면

iOS가 제한 대상 앱/웹 사이트 위에 띄우는 차단 화면입니다.

#### 기본 Shield

| 항목 | 설명 |
| --- | --- |
| 제목 | 짧은 GoldTime식 문구 중 하나를 무작위로 표시한다. |
| 부제 | `더 쓰려면 GoldTime에서 선택하세요.` |

보조 버튼을 누르면 익스텐션이 앱을 직접 열 수 없기 때문에 GoldTime 복귀 알림을 예약하고,
사용자가 알림을 눌러 앱으로 돌아오게 합니다.

| 기본 버튼 | `그만 쓰기` |

### 5.10 잠금 선택지

Shield에서 GoldTime 복귀 알림을 누르거나, 홈의 잠긴 그룹에서 `추가 사용`을 누르면 표시됩니다.

#### 진입 맥락

- 특정 앱/웹 사이트에서 들어온 경우, 해당 항목이 포함된 잠긴 그룹을 우선 찾는다.
- 잠긴 그룹이 1개면 자동 선택한다. 여러 개면 사용자가 한 그룹을 고른다.
- 한 번에 한 그룹만 연장할 수 있다.

#### 선택지

| 선택지 | 효과 | 제한 |
| --- | --- | --- |
| 그만 쓰기 | 잠금을 유지하고 화면을 닫는다. 광고 없음. | 잠긴 그룹이 있으면 그만 쓰기 기록이 증가한다. |
| 1분만 더 쓰기 | 선택한 그룹을 60초 연장한다. | 하루 5회. 23:45 이후에는 제공되지 않는다. |
| 광고 보고 10분 구매하기 | 보상형 광고 후 선택한 그룹을 10분 연장한다. | 23:45 이후에는 `광고 보고 자정까지 열기`로 바뀐다. |

- **자정 근처 처리**: 23:30부터 안내 문구가 나오고, 23:45부터는 1분 연장이 불가능해진다
  (남은 시간이 1분 미만이라 정확히 차감할 수 없기 때문). 이때 광고 연장은 "자정까지"로 동작한다.
- 연장 불가 기간 중인 그룹에서는 연장 버튼 대신 만료일 안내 카드가 표시된다.

#### 연장 완료

- 어떤 그룹을 몇 분 연장했는지 알려준다.
- 연장 시간이 지나면 다시 잠긴다고 안내한다.
- 같은 앱/웹 사이트가 다른 잠긴 그룹에도 포함되어 있으면, 아직 잠긴 그룹이 남았다고 알려준다.

#### 재잠금 타이머 실패

연장은 항상 "해제 후 다시 잠금"이 보장되어야 합니다. 재잠금 타이머 등록에 실패하면 잠금을
유지하고 자동 재시도를 시작합니다.

- 화면에 실패 메시지를 표시한다.
- 짧은 간격으로 자동 재시도하고, 사용자가 `다시 시도`를 직접 누를 수도 있다.

### 5.11 보상형 광고 화면

광고 연장, 규칙 변경 게이트, 항목 편집/삭제 게이트에서 사용합니다.

| 상태 | 표시/동작 |
| --- | --- |
| 안내 1단계 | 규칙 변경 게이트는 광고를 바로 띄우지 않고 "광고를 봐야 한다"는 안내 → 확인을 먼저 거친다. |
| 광고 준비 중 | 검은 배경, `광고 준비 중`, ProgressView, 취소 버튼을 표시한다. |
| 광고 표시 가능 | 보상형 광고를 자동 표시한다. |
| 광고 성공 | 호출한 흐름의 완료 콜백을 실행한다(10분 연장, 규칙 저장, 항목 편집 진입, 그룹 삭제). |
| 광고 취소/보상 없음 | 호출한 흐름의 취소 콜백을 실행한다. |
| 광고 로드 실패 | fallback 화면을 보여준다. 사용자가 fallback 버튼을 누르면 완료 처리한다. |

## 6. 기능별 명세

### 6.1 그룹 관리

#### 제한

| 규칙 | 현재값 |
| --- | --- |
| 최대 그룹 수 | 5개 |
| 그룹당 제한 항목 수 | 앱/웹 사이트 합계 9개 |
| 전체 Shield 앱 수 제한 | 앱 토큰 union 기준 49개 |
| 기본 그룹명 | `그룹 1`, `그룹 2` ... |
| 1분 연장 하루 한도 | 5회 |

#### 모니터링 대상 조건

다음을 모두 만족하는 그룹만 추적·집행 대상이 됩니다.

- **적용됨(`isApplied`)** — draft 그룹은 저장은 되지만 보호가 시작되지 않는다.
- 앱 또는 웹 사이트가 1개 이상 있다.
- 규칙이 선택되어 있고 유효하다(일일 한도 0분 이상 / 시간대 정책 통과 / 쿨다운 범위 통과 /
  요일별 규칙 7일 검증 통과).
- 앱/웹 사이트 합계가 9개 이하이다.
- 카테고리 토큰이 남아 있지 않다.

저장 과정에서 앱/웹 사이트 토큰만 남기므로 카테고리 선택은 실질적으로 제한 대상에서 제외됩니다.

### 6.2 자동 모니터링

GoldTime은 모니터링 대상 그룹마다 독립적인 DeviceActivity 모니터링을 등록합니다.

| 규칙 | 등록 형태 |
| --- | --- |
| 일일 한도 | 하루 스케줄 + 1분 threshold 이벤트. 도달할 때마다 사용 시간 1분 증가, 한도 이상이면 잠금. |
| 시간대별 차단 | 시간대마다 interval 스케줄. 시작 시 잠금, 종료 시 해제. |
| 쿨다운 | 사용 예산 추적 activity + 휴식 타이머 activity. 예산 소진 → 휴식 시작, 휴식 종료 → 재충전 후 예산 activity 재등록. |
| 요일별 | 오늘 요일로 투영한 규칙을 위 3종 중 하나로 등록하고, 자정에 다음 요일 규칙으로 재등록. |

#### 동기화 시점

- 앱 실행/활성화 시.
- 그룹 적용/삭제/규칙 변경/항목 변경 후.
- 설정의 스크린 타임 재연결 실행 시.
- 자정 하트비트(extension) 및 백그라운드 작업.
- 연장 만료 여부를 확인하는 홈의 주기적 refresh 시.

### 6.3 Shield 적용

잠긴 그룹들의 앱 토큰과 웹 도메인 토큰을 합쳐 하나의 Shield union으로 적용합니다.
한 앱이 여러 그룹에 들어 있으면, **한 그룹만 연장해도 다른 잠긴 그룹 때문에 계속 잠겨 있을 수 있습니다.**

### 6.4 연장

#### 1분 연장

- 선택한 잠긴 그룹만 60초 동안 임시 해제한다.
- 하루 5회까지. 23:45 이후에는 제공하지 않는다.
- 성공 시 오늘 1분 연장 사용 수가 증가하고, 홈의 `남은 1분 연장`이 즉시 갱신된다.

#### 광고 연장

- 보상형 광고를 완료하면 선택한 잠긴 그룹만 10분 동안 임시 해제한다.
- 23:45 이후에는 자정까지 열어주는 시간 기반 해제로 동작한다.
- 성공 시 오늘 광고 개수와 광고 연장 시간이 증가한다.
- 광고 로드 실패 시 fallback 버튼으로 완료 처리할 수 있다.

#### 재잠금

- 연장할 때 해당 그룹에 대한 override 모니터링을 등록한다.
- override 시간이 끝나면 임시 해제를 풀고 Shield를 다시 적용한다.
- 쿨다운 그룹의 휴식도 연장으로 건너뛸 수 있다(연장이 끝나면 원래 휴식 상태로 돌아간다).

### 6.5 광고 게이트 (우회 방지)

**적용된(applied) 그룹**을 무르는 행동에는 보상형 광고 관문이 붙습니다.
draft 그룹은 게이트 없이 자유롭게 편집·삭제할 수 있습니다.

| 행동 | 게이트 시점 |
| --- | --- |
| 규칙 변경 | **완료(커밋) 시점.** 규칙 편집기를 열어 보기만 하는 것은 무료다. |
| 제한 항목 편집 | 편집 진입 시점. |
| 그룹 삭제 | 삭제 시점. |
| 그룹명 변경 | 게이트 없음(집행과 무관). |

- 규칙 변경 게이트는 **집행에 영향 있는 변경**일 때만 뜬다. 표시 전용 플래그만 바뀐 커밋이나
  검증에 실패할 상태는 광고 없이 통과시킨다.
- 게이트를 완료하면 원래 하려던 작업이 이어진다. 광고를 불러올 수 없으면 fallback 버튼으로
  작업을 계속할 수 있다.
- 연장 불가 기간 중에는 게이트 이전 단계에서 차단되고 만료일을 안내한다(광고 자체가 뜨지 않는다).

### 6.6 일일 리셋

날짜가 바뀌면 다음 상태를 초기화합니다.

- 1분 연장 사용 횟수
- Shield 활성 상태, 잠긴 그룹 목록, 연장 상태
- 마지막 잠금 해제 요청 토큰, Shield 열기 요청
- 그룹별 사용 시간, 마지막 등록 그룹 기록

일별 통계는 유지됩니다. 요일별 규칙 그룹은 자정에 다음 요일 규칙으로 재등록됩니다.

### 6.7 통계 값

#### 일별 저장 값

| 값 | 설명 |
| --- | --- |
| `adWatchCount` | 광고를 보고 연장한 횟수. |
| `adUnlockedSeconds` | 광고로 얻은 추가 사용 시간. |
| `oneMinuteUsedCount` | 1분 연장 사용 횟수. |
| `shieldHitCount` | Shield에 도달한 횟수. |
| `walkAwayCount` | 그만 쓰기를 선택한 횟수. |

#### 계산 값

| 값 | 계산 |
| --- | --- |
| 총 추가 사용 시간 | `adUnlockedSeconds + oneMinuteUsedCount * 60` |
| 예상 광고 수익 | `adWatchCount * 100원` |
| 오늘 비교 | 오늘 추가 사용 시간 - 어제 추가 사용 시간 |
| 주간 비교 | 이번 주 추가 사용 시간 - 지난 주 추가 사용 시간 |
| 광고 없는 연속 일수 | 오늘부터 과거로 보며 광고 수가 0인 날의 연속 길이 |
| 최고 광고 없는 연속 일수 | 기록 시작일부터 현재까지 광고 수 0인 연속 구간의 최댓값 |

예상 광고 수익은 제품 농담과 내부 표시용 추정치이며 실제 정산 금액으로 취급하지 않습니다.

### 6.8 권한

| 권한 | 필수 여부 | 이유 |
| --- | --- | --- |
| Screen Time / Family Controls | 필수 | 앱/웹 사이트 선택, 사용 시간 추적, Shield 적용에 필요하다. |
| 알림 | 사실상 필수 | Shield Action Extension에서 앱을 직접 열 수 없으므로 GoldTime 복귀 알림에 필요하다. |
| 앱 추적 투명성(ATT) | 선택 | 맞춤 광고 품질을 위한 흐름이며 거부해도 앱 사용 자체는 계속 가능하다. |

- Screen Time 권한이 없어지면 권한 복구 화면을 띄운다.
- 알림 권한이 없으면 온보딩 또는 설정에서 다시 안내한다.

## 7. 연장 불가 모드 (기간 강력 잠금)

> 상태: 구현 완료(2026-07-13, `Feat/AbsoluteLock`) — 실기기 검증 세션 1~3 통과, 잔여 항목은
> `TODO.md` 참조. 런북: [verify-strictlock-runbook](verify-strictlock-runbook.md).
> 1.3.0에서 **무료 베타**로 출시하고 이후 유료 구독으로 전환할 계획이다.
> 결정 근거·트레이드오프는 `docs/agent/decision-context.md`의 ADR 참조.

### 개념

- 그룹별 opt-in 자기 연장 불가 기간 모드. 규칙 집행은 평소대로 굴러가고(자정 리셋·요일 전환·쿨다운
  재충전 포함), **도망갈 문(연장·규칙 편집·삭제)만 기간 동안 잠근다**.
- 켤 때 기간을 고르고, **중도 해제는 어떤 수단으로도 불가**하다. 만료 시 자동 해제된다.
- 긴급 탈출구는 의도적으로 없다(Opal식 Emergency Pass 미도입).

### 기간

- 빠른 선택 칩 1일 / 3일 / 7일 + **직접 입력**(휠, 1~30일). **기본 선택은 1일 칩**(휠은 접힌 채로
  열리고, 커스텀 칩을 눌러야 14일에서 펼쳐진다 — 2026-07-31 변경, 이전 기본값은 커스텀 14일).
  **상한 30일은 실수 보호** —
  한 번 걸면 어떤 수단으로도 못 푸는 모드라 무한정 긴 기간은 도움이 아니라 사고가 된다.
  범위 검증은 Domain(`ManageGroupsUseCase.strictLockDayRange`)이 최종 방어.
- 만료 시각은 항상 자정 경계: N일 연장 불가 기간 = 오늘 포함 N일, 만료 = 마지막 날 다음 0시.
  **단 UI 표기는 "마지막 날 23:59까지 잠겨요"**(`goldTimeStrictLockedUntilText` — 저장값에서 1초를
  빼 마지막 잠금 날을 보여준다). "7/14 0시에 풀려요"는 사람에겐 하루 밀린 느낌이라 쓰지 않는다.
  예: 7/12에 3일 → 7/15 00:00 해제. "모든 잠금은 하루 단위" 주기와 일치한다.
- 연장 불가 기간 중 기간 추가(연장)는 허용, 축소는 불가(강화 방향만).

### 기능 토글 (설정 → 연장 불가 모드 토글, **기본 Off**)

- 연장 불가 모드는 **옵트인 기능**이다. 설정에서 켜야 그룹 카드에 연장 불가 행이 나타나고 켤 수 있다.
  꺼져 있으면 카드에 행 자체가 없고 진입·활성화가 모두 거부된다(Domain `activateStrictLock`도 방어).
- **진행 중인 연장 불가 기간이 있으면 토글을 끌 수 없다** — 기능을 끄는 것으로 연장 불가 기간을 우회 해제하는 구멍을
  막는다(`ManageGroupsUseCase.setStrictLockEnabled` → false). 토글을 잠그고 이유를 캡션·alert로 알린다.
- 켜기는 언제나 가능. 저장 위치는 `SharedStore.isStrictLockEnabled`(App Group, 기본 false).

### 켜기 조건·흐름

- 기능 토글 On + applied + 유효 규칙(invalidReason 없음) 그룹만 켤 수 있다. draft 불가.
- 흐름: 그룹 카드 → 연장 불가 모드 진입 → 기간 선택 → 고지 화면 → 강한 확인(2단계).
- 고지 화면 5행 + 그룹 재확인. **주 문장은 사용자가 겪는 결과, 수단·부작용은 각주로 내린다**
  (수단을 앞세우면 "왜 날짜를 건드리지?" 같은 의심이 먼저 온다):
  ① 중도 해제 불가 ② 규칙 변경·삭제 잠금 ③ 1분·광고 연장 잠금
  ④ "GoldTime 앱을 삭제할 수 없어요" — 각주: iOS 제약이라 이 기간엔 기기의 다른 앱 삭제도
  함께 막힌다(고지 의무) ⑤ "시간을 돌려서 해제할 수 없어요" — 각주: 날짜·시간이 자동 고정된다.
- **켜기 화면에서 "권한을 끄면 풀린다"는 안내는 하지 않는다**(2026-07-13 결정). 사실이지만
  잠그려는 순간에 탈출 방법을 알려주는 셈이라 모드의 목적을 스스로 무너뜨린다. 권한 철회는
  이미 풀린 뒤(복구 화면)에만 다룬다 — 아래 "권한 철회" 절.
- **켜기는 무료**(광고 없음) — "강화는 무료, 완화에 통행료" 철학 유지.
- 확정 직후 홈 복귀 시 시작 알럿 + **묵직한 두 박 햅틱**(소리 없음)으로 무게를 전한다.
  이미 연장 불가 중인 그룹의 기간을 늘리면 "기간을 늘렸어요" 알럿이 대신 뜬다.

### 연장 불가 기간 중 잠기는 것

| 표면 | 동작 |
| --- | --- |
| 1분 연장·광고 연장 | 거부. 쿨다운 **휴식 중 해제(건너뛰기)** 포함 — 쿨다운 ADR("휴식도 비용을 치르면 풀 수 있다")의 의도된 예외. **휴식 자체는 평소대로 시간이 지나면 끝나고 예산이 재충전된다**(집행 규칙은 연장 불가 모드와 무관 — 연장 불가 모드는 "돈으로 건너뛰기"만 막는다). |
| 규칙 편집 | 전면 차단(강화 방향 포함 — 판별 없이 단순 차단). 진입 시 만료일 안내. |
| 그룹 삭제 | 차단. 만료일 안내. |
| 기기 앱 삭제 | `denyAppRemoval` — **기기 전체** 앱 삭제가 막힌다(Apple 제약, 전역). |
| 수동 날짜·시간 변경 | `requireAutomaticDateAndTime` — 시계를 내일로 돌려 자정 리셋을 발화시키는 우회 봉쇄. |

### 잠기지 않는 것

- 규칙 자체의 집행(자정 리셋, 요일별 규칙 전환, **쿨다운 휴식 종료·예산 재충전** 전부 평소대로).
  → 5분 쓰고 30분 휴식이면 30분 뒤 정상적으로 풀린다. 연장 불가 모드는 그 30분을 **광고로 건너뛰는 것**만
  막는다. 재충전 경로(`endCooldownAndRecharge`/`handleCooldownTimerEnded`/
  `rechargeExpiredCooldowns`)에 strict guard를 넣으면 휴식이 영영 안 끝난다 — 넣지 말 것
  (회귀 테스트 `cooldownRestStillEndsAndRechargesDuringStrictLock`가 고정).
- 그룹명 변경, 다른 그룹의 편집·연장·삭제, 새 그룹 생성, 통계·설정 화면.

### 연장 불가 기간 중 표시

- 그룹 카드에 연장 불가 배지 — 문구는 **"N일 남음"**(`home.badge.strict`). **D-N 표기는 금지**
  (D-day 관습상 "연장 불가가 N일 뒤 시작"으로 읽힌다 — 2026-07-29 실사용 피드백,
  `Presentation/CLAUDE.md`의 표기 계약 ②).
- 연장 불가 행 제목은 적용 전 "연장 불가 모드 설정" → 적용 중 "연장 불가 중"으로 바뀌고,
  부제는 만료일("%@ 23:59까지")을 보여준다.
- Shield "GoldTime 가기" → 잠금 선택지 화면에서 연장 버튼 대신 "연장 불가 모드 — 만료일" 안내.

### 권한 철회 (수용하는 구멍)

- Screen Time 권한 철회 시 Shield·denyAppRemoval이 모두 풀린다(Apple 제약 — 어떤 앱도
  API로 못 막는다). 스크린타임 암호 안내 방식은 검토 후 제외했다(2026-07-12 사용자 결정).
- **켜기 화면에서는 이 구멍을 안내하지 않는다**(위 참조). 대응은 사후에만: 미승인 + 연장 불가 기간 활성
  감지 시 복구 화면에 연장 불가 기간 상태 강조·재승인 유도(`recovery.strictNotice`), `strict_revoke_detected`
  분석 이벤트 기록.
- 연장 불가 기간은 SharedStore에 보존되어 재승인 시 그대로 복원된다(철회로 연장 불가 기간이 리셋되지 않는다).

### 만료

- 만료 후 첫 동기화에서 자연 복귀(별도 상태 전환 이벤트 없음 — 판정은 항상 `strictUntil > now`).
- 연장 불가 기간 활성 그룹이 0개가 되면 전역 설정(denyAppRemoval·자동 날짜 강제)을 해제한다.
  자정 만료는 DeviceActivityMonitorExtension의 자정 재무장에서도 재평가한다.
- 완주 축하·재연장 불가 기간 제안은 선택 사항(1.3.0 개선 후보 — `TODO.md`).

## 9. 현재 주의할 점

- 웹 사이트 제한은 Safari 사용 맥락에서만 적용된다고 안내한다.
- 카테고리 제한은 저장 대상에서 제외된다.
- 시뮬레이터만으로 Screen Time, Shield, FamilyControls 흐름을 완료 검증할 수 없다.
- Shield에서 앱을 직접 여는 것은 불가능하므로 알림을 통해 앱 복귀를 유도한다.
- 광고 게이트 기준은 "잠긴 그룹"이 아니라 **"적용된 그룹"**이다(applied ⊃ locked ∪ override).
- 여러 그룹에 같은 앱이 들어갈 수 있고, 한 앱이 여러 잠긴 그룹에 걸리면 한 그룹만 연장해도 다른 그룹 때문에 계속 잠겨 있을 수 있다.
- 시간대는 15분 미만·자정 넘김이 불가능하다(DeviceActivitySchedule 제약).
- 연장 불가 모드의 전역 설정(앱 삭제 차단·날짜 자동 고정)은 GoldTime만이 아니라 **기기 전체**에 걸린다.
